## 🔄 Histórico de Versões (Releases)

### 📌 v1.0.0 - Versão Funcional
* **Foco:** Implementação das regras matemáticas e algoritmos de sorteio anti-duplicação de dados para os jogos da Mega-Sena, Quina e Lotofácil.
* **Estética:** Visual rudimentar em HTML puro.

### 📌 v2.0.0 - Interface Avançada (Versão Final)
* **Foco:** Design de interface do usuário (UI).
* **Melhorias Estéticas:** Introdução de CSS responsivo, transformação dos resultados textuais em esferas coloridas idênticas às dos sorteios reais da Caixa, e efeitos de transição visual ao clicar nos botões.
